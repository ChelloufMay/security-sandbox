# Security Sandbox
Security Sandbox is an educational, security-focused web application designed to demonstrate and experiment with common web security mechanisms in a realistic full-stack setup. Its purpose is to provide a safe environment to explore authentication and authorization concepts (such as login, registration, email verification, CSRF protection, cookies, roles, and audit logs), frontend–backend interactions, and secure development practices, all while running locally with Docker, HTTPS (via mkcert), and modern tooling (Django + Vite/React). The project is intentionally structured to mimic real-world conditions—same-origin HTTPS, reverse proxying, and isolated services—so developers and students can understand why security measures exist and how they behave in practice without risking production systems.
